## 📌 Sobre o Projeto
Este projeto é uma aplicação web interativa desenvolvida como trabalho avaliativo (19/09). A página simula uma transmissão televisiva bem-humorada com foco no Vasco da Gama, utilizando elementos dinâmicos para prender a atenção do utilizador e culminando numa escolha interativa direcionada ao professor.

## 🚀 Funcionalidades
- **Interface Dinâmica:** Transição suave entre múltiplas telas ocultas (Início, Transmissão, Escolha e Fim) utilizando manipulação do DOM.
- **Sincronização de Mídia (Event Listeners):** O JavaScript monitora o tempo exato do áudio (`timeupdate`) para acionar animações CSS e pausar a execução em momentos pré-definidos.
- **Animações CSS Keyframes:** Efeitos de TV ligando, letreiro rotativo e elementos pulsantes.
- **Lógica de Decisão:** Um quiz humorístico final ("E agora, professor?") contendo uma equação trigonométrica estruturada para resultar na nota máxima da atividade.

## 🛠️ Tecnologias Utilizadas
- **HTML5:** Estruturação semântica das telas e integração de áudio.
- **CSS3:** Estilização, layout flexível (`Flexbox`) e animações (`@keyframes`).
- **JavaScript (Vanilla):** Lógica de eventos, controle de áudio e manipulação de classes/estilos em tempo real.
